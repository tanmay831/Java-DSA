# Multithreading Notes Quick Reference 🧵

For full, detailed study notes on Java Multithreading & Concurrency, see:
👉 [04_Multithreading_Notes.md](./04_Multithreading_Notes.md)

### Key Takeaways:
- **Creation**: Extend `Thread` or implement `Runnable`/`Callable`.
- **Synchronization**: `synchronized` methods/blocks or explicit `ReentrantLock`.
- **Inter-Thread Communication**: `wait()`, `notify()`, `notifyAll()` or `Condition`.
- **Concurrency**: `ExecutorService`, `AtomicInteger`, `ConcurrentHashMap`, `CountDownLatch`, `Semaphore`.
